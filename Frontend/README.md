# truss Frontend (Vite)

This frontend uses React + Tailwind CSS and is built with Vite.

## Scripts

Run commands inside `Frontend/`:

### `npm run dev`

Starts the Vite development server with hot reload.

### `npm run build`

Builds production assets into the `dist/` directory.

### `npm run preview`

Serves the production build locally for verification.

## Notes

- Entry HTML file: `index.html`
- React entry point: `src/index.js`
- Public static assets remain in `public/` (referenced from `/`)
